# GiftLink User Stories
## User Story Template
**As a** [type of user]
**I want** [an action or feature]
**So that** [benefit or reason]
---
## User Stories
### 1. User Registration
**As a** new user
**I want** to create an account
**So that** I can use GiftLink to give away or find free household items.
### 2. User Login
**As a** registered user
**I want** to log in securely
**So that** I can access my GiftLink account.
### 3. Create Gift Listing
**As a** user
**I want** to create a listing for an item I no longer need
**So that** another person can receive and reuse it.
### 4. Search Items
**As a** user
**I want** to search for available items
**So that** I can find things that I need.
### 5. Filter Items by Category
**As a** user
**I want** to filter items by category
**So that** I can find relevant items more easily.
### 6. View Item Details
**As a** user
**I want** to view detailed information about an item
**So that** I can decide whether the item is suitable for me.
### 7. Comment on Items
**As a** user
**I want** to comment on an item
**So that** I can ask questions or provide information about it.
### 8. Update User Profile
**As a** registered user
**I want** to edit my profile information
**So that** my account information remains up to date.
